## Mapping to the site template

The YAML front matter carries every field the live article page renders: `category` (the small caps label), `title` (H1), `seo_title` (title tag), `description` (deck + meta description), `author`, `reviewed_by`, `published`, `read_time`, `hero_image` + `hero_alt` (the image inside the Short Answer box, also the OG image), `related_treatment_pages`, `read_next`. `slug` / `es_slug` pair the EN and ES versions for the hreflang links.

In the body: the first `## SHORT ANSWER` / `## RESPUESTA CORTA` block is the callout; every other `##` is an H2 that feeds the "In this article" list; the `>` blockquote with the doctor's name in caps is the pull-quote; `## Related questions` / `## Preguntas relacionadas` holds six `###` FAQ items, each followed by the answering doctor's name on its own line (this is the FAQPage schema source). Internal links use site-relative paths (`/blog/...`, `/es/blog/...`, `/free-photo-evaluation`).
